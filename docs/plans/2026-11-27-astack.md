# AStack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build AStack, a Claude Code plugin with a `/astack` router mode. It takes a JS/TS web task, either a spec or an issue queue, through to a green, self-reviewed PR and notifies the human. It never merges.

**Architecture:** AStack is a markdown-first plugin: skills, playbooks, agents, and principles. A small set of zero-dependency TypeScript scripts, run directly by Node, handles the deterministic parts: config, stack detection, the SessionStart hook, worktrees, evidence upload, issue sources, PR watching, and a residue lint. Language-agnostic PStack content is ported through a fetch script pinned to one commit and then hand-edited. The router, playbooks, reviewers, packs, and Phoebe are written fresh for Claude Code.

**Tech Stack:** Claude Code plugin format (`.claude-plugin/`, `skills/`, `agents/`, `hooks/`), Node ≥ 22.18 (native TS type stripping), `node:test`, `gh` CLI, `git worktree`, Linear MCP (optional), Playwright (optional, in target repos).

**Spec:** `docs/specs/2026-11-27-astack-design.md`. Read it before any task. Section numbers below (§) refer to it.

## Global Constraints

- Claude Code only. No Cursor terms anywhere in shipped files. `scripts/lint.ts` enforces this from Task 2 on, and every later task must pass `npm run lint`.
- Plugin name `astack`. Skills are invoked as `/astack:<name>`. Install: `/plugin marketplace add <path-or-repo>` then `/plugin install astack@astack`.
- Scripts: TypeScript run with `node <file>.ts` (Node ≥ 22.18). **Zero runtime dependencies.** Dev dependencies are limited to `typescript` and `@types/node`. Scripts import only `node:*` modules and the plugin's own files, and use `.ts` extensions in import specifiers.
- Skills locate scripts from their own base directory, as `<skill base dir>/../../scripts/<name>.ts`. Hooks use `${CLAUDE_PLUGIN_ROOT}/scripts/<name>.ts`.
- Models are never hard-coded in skills. Each spawn reads `node scripts/config.ts model <role>`, which prints `<model> <effort>`, and passes both values to the Agent tool. `model` ∈ {`opus`,`sonnet`,`haiku`,`fable`}.
- AStack never runs `gh pr merge`, never deploys, and never force-pushes a shared branch. The lint fails on `gh pr merge` in any shipped file.
- Router `skills/astack/SKILL.md` ≤ 150 lines. Each playbook ≤ 60 lines. The lint enforces both.
- PStack source is pinned at commit `b7b93c36be9bcc36a74db438e0fd385d660bc559`. MIT license. Ported files keep attribution through `NOTICE`.
- Character names (Jinhsi, Phoebe, Shorekeeper, Encore, Xiangli Yao, Verina, Zhezhi) are internal only. They must not appear in `plugin.json` `name`/`description` or the marketplace entry. The lint enforces this.
- Wording rules for all skill prose: short declarative sentences and web-flavored examples. Follow PStack's tone.

## Review Focus

1. **Config file missing, empty, or malformed JSON, or an unknown model alias.** Expected: defaults are used and a one-line warning goes to stderr. No crash, and the SessionStart hook still exits 0. Tests are in Tasks 3 and 5.
2. **Monorepo, where the framework lives in `apps/*` or `packages/*` rather than the root.** Expected: detection finds Nuxt in `apps/web` and returns it. Tests are in Task 4.
3. **No GitHub remote, or `gh` missing or unauthenticated.** Expected: the issue, evidence, and watch scripts exit with code 2 and the one-line message `astack: GitHub unavailable: <reason>`. Skills print the `Skipped: … ` line and continue. Tests are in Tasks 10, 13, and 14.
4. **Worktree slot whose port is already in use, or a repo with no `.env*` files.** Expected: the next free port is chosen and an empty env list is fine. Tests are in Task 10.
5. **An issue closed, or assigned to someone else, between list and claim.** Expected: `claim` reports `skipped` and the loop moves on. Tests are in Task 14.

- Produces:
  ```ts
  class GitHubUnavailable extends Error {}               // message: "astack: GitHub unavailable: <reason>"
  function run(cmd: string, args: string[], cwd: string): string   // throws on non-zero
  function repoSlug(cwd: string): { owner: string; repo: string }  // throws GitHubUnavailable
  interface Slot { branch: string; path: string; port: number; envFiles: string[]; installed: boolean }
  function freePort(start: number, isFree?: (p: number) => Promise<boolean>): Promise<number>
  ```

  - port = `freePort(basePort + slot)`.
  - Creating an existing slot is idempotent: it returns the existing Slot.
- `scripts/config.ts` gets no change. `devServer.basePort` defaults to `3100` when unset.
